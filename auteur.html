Application développée par Maxence Français.

Projet réalisé lors d'un TP Vue.js du module Technologies de l'internet, en licence professionnelle Développement Logiciel et Web Mobile (DLWM). L'objectif : construire une application interactive autour d'une API REST publique, avec les directives de Vue (v-for, v-if, v-model), des propriétés calculées et des composants.
